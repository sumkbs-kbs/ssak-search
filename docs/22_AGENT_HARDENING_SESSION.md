## 2. 출발점: 제1원칙 평가가 발견한 것

토큰 효율·SNR·지연·최신성 4축으로 에이전트 접점(`src/mcp-standalone.ts`, `/api/agent/*`, 오케스트레이터, 추출기)을 분해한 결과:

1. **`ssak_deep_research`가 도구 설명("parallel")과 달리 직렬 for-loop** — 최악 110초
2. **"4-tier stealth"가 허위** — 코드엔 3티어, 스탠더얼론 바이너리에선 sidecar 미주입으로 실제 2티어
3. **모든 추출 티어 실패 시 하드코딩 403 반환** — 404/DNS/타임아웃이 전부 BOT_BLOCKED로 오보
4. **에이전트 경로 신규 코드의 테스트 커버리지 0건**
5. (배치 진행 중 발견) **`/api/agent/*` 3개 엔드포인트가 완전 무인증** — 배포 IP 밴의 직접 레버

## 3. 배치별 작업 기록

### 배치 1 — 에이전트 도구 경화 기본 (커밋 `c48443a`)

- **deep_research 병렬화**: 동시도 3 배치(`Promise.allSettled`), 개별 소스 실패 격리. 실측: 2소스 총 2,162ms = 검색 588ms + 추출 최대값(합이 아님) — 이전엔 ≈5초+
- **에러 상태 전파**: Tier-1에서 `res.status` 캡처, 404/410/401 즉시 확정 실패(하위 티어 17초 낭비 제거), 택소노미 신설 `PAGE_NOT_FOUND`/`AUTH_REQUIRED`/`CONTENT_TOO_SPARSE`, 우선순위 규칙(확정 상태 > 희소본문, 429는 프록시 상태로 제외)
- **토큰 카운터 단일화**: `estimateTokens`/`charsPerToken`(한국어/CJK 보정) 도입, `/3.5` 하드코딩 8곳 교체 — 한국어 1,000자가 286→667 토큰으로 정확 측정되어 예산 실제 작동
- **zod→MCP 스키마 단일화**: `z.toJSONSchema(io:'input')` 생성으로 이중 정의 제거, 검증 실패 `isError: true` 구조화, `z.coerce`, `strip_links` 실구현
- **JSON-RPC 준수**: 미지원 method `-32601` 응답(무응답=클라이언트 영구 대기 해소), `initialize` protocolVersion 반영

### 배치 2 — 품질·속도 (같은 커밋에 포함)

- **fast-path**: authority hostname 절미치 매칭(경로 트릭 차단), medium/dev.to 제외, 서브쿼리 언어 판별, 영어 쿼리 bing+DDG 다양화, 스코어 랭크 감쇠 사전값(플랫 0.85 폐지), `signal_confidence` 정직화(HIGH=2개 이상 0.75+)
- **마크다운**: 링크 보존+절대 URL화(go.dev 실측 0→33개), 제목 레벨 보존, 중첩 article/main 균형 추출, article 내 header(제목) 유지
- **stream-search 실스트리밍**: `onHits` 리스너로 백엔드 도착순 방출(TTFT=첫 백엔드 응답)
- **tiered-fanout**: tier0/tier1 동시 시작(콜드 self-index 2.5s 지연 제거)
- **데드코드 1,900+ 라인 삭제**: query-router(955), edge-cache(298), hybrid-ranker(265), fanoutBackends 레거리 (PHASES는 부하모델 의존으로 유지 — 삭제 검증 중 발견해 롤백한 사례)

### 배치 3 — 신선도·한국어 품질 (커밋 `c48443a`에 포함)

- **뉴스 캐시 TTL 30분→5분** (메모리+Cache API, B.1 결정 번복) + `cached_at`/`cache_age_ms` 노출
- **naver 링크 하베스팅 노이즈 필터**: 지식인 프로필/카페·블로그 프론트 도어/"N만 인용" 인플루언서 카드 차단 + href `&amp;` 미디코드 버그 수정 + fast-path 노이즈 플로어(0.10). 라이브: "클라우드플레어 CPU 제한" 상위 히트가 프로필카드(0.05)→공식 문서(0.75)
- **DDG 202 쿨다운 가시화**: `aborted_backends`에 `duckduckgo(antibot-cooldown)` 마킹

### 배치 4 — 보안 구멍·백본 (커밋 `c48443a`에 포함)

### 배차 6 — 완성도 평가 → 권고 실행 (커밋 `3b15fe6`~`2b141bf`)

냉정 평가에서 **수정보다 큰 구멍** 발견: 전 라우트 프로브로 `POST /api/research`가 무인증 200(4.5초/15소스 풀 파이프라인 무료)임을 실측.

- **중앙 인증 게이트**: 14개 무인증 라우트를 `API_AUTH_GATED_PREFIXES` 단일 정책 테이블 + 공유 `requireApiAuth`로 봉인 (파일별 수정 대신 감사 가능한 한 곳 정책). 21라우트 401을 workerd 통합테스트 7개로 고정
- **평가 샘플 게이트**: `--sample <n>` 언어 층화 결정적 샘플링(풀suite 16분→12쿼리 2분), `npm run eval:sample`
- **아티팩트 오염 방지**: 샘플 실행이 공식 `latest.json`(113,639라인)을 덮어쓰던 것 차단(`sample-latest.json` 분리) — 커밋 stat의 −113,145에서 감지

### 배치 7 — 근본원인 규명·단일-플라이트 (커밋 `2b141bf`·`36b4060`)

ja/zh 골드 nDCG 하락(0.89→0.49) 추적 — **가설 3건을 A/B로 기각하며 진행**:

1. CJK 트렁케이션 가설 → 되돌려도 0.4935 불변 → 기각
2. freePlan 타임아웃 가설 → 되돌려도 불변 → 기각
3. 골드 대조 → 사라진 도메인 3개가 정확히 DDG 상위 히트 → **단발 휴식 시엔 파이프라인이 `bing+duckduckgo+wikidata` 정상 생산 실증** → 결론: **세션 내 측정 케이던스가 이 IP의 DDG 안티봇 평판을 소진**시킨 환경 요인. 평판 회복 후 ja-fact-01 **0.8278 복원으로 최종 입증**

부산물로 올바른 수정 2건: 로컬 레이트리밋 폴백이 DDG 분당 창 강제(프로덕션 DO 동등화), 샘플 층화 라운드로빈 인터리브(마지막 스트라텀에 버스트밴 집중 방지).

- **fast-path 단일-플라이트**: 동시 중복 쿼리(서브에이전트 팬아웃)를 하나의 팬아웃으로 병합, 조인은 자체 `onHits` 재생+자체 벽시간 보고

## 7. 알려진 한계·남은 과제 (외부 자원 의존)

1. **백엔드 구조 불변**: HTML 스크래퍼 3개 + 단일 egress IP — Brave API 키(무료 2,000/월) 확보 시 fast-path 통합 30분 작업, bing 영어 평균 0.27의 근본 해결
2. **무인증 IP 레이트리밋 per-isolate**: 엣지 분산 시 실효 한도 희석(실측 65회 미발생) — 볼류메트릭 방어는 Cloudflare Rate Limiting 룰 권장, 앱 내 정밀 한도는 DO 이관
3. **평가 기준선의 DDG 평판 민감성**: 회복일 풀런 재베이스 권장
4. **스탠더얼론 바이너리 Tier-3**: `SIDECAR_URL` 설정 시 활성 (코드·테스트 준비 완료, `sidecar/` Docker 패키지 저장소 내장)
5. **미측정**: fast-path `signal_confidence` 밴드의 nDCG 캘리브레이션, 통합 테스트 커버(agent-auth 7개뿐)

## 8. 방법론 교훈 (재사용 가능)

1. **모든 주장은 실측으로**: 세션의 모든 기능 주장에 라이브 측정값이 붙었고, 두 번의 냉정 평가 모두 "직전 배치가 놓친 것"을 프로브로 잡아냄(agent 무인증, research 무인증)
2. **가설→A/B→귀속**: ja/zh 사건에서 3개 가설을 기각하고 환경 요인으로 확정 — 결정적 재현성이 원인 단정의 근거가 아님을 증명한 사례
3. **커밋 stat을 읽어라**: −113,145라인이 이상해서 발견한 아티팩트 오염
4. **정직한 문서**: "4단계 스텔스" 같은 마케팅 표현은 에이전트의 도구 선택을 오염시킨다 — 최초 평가의 지적이 문서 동기화까지 일관되게 반영됨
